---
title: Flow doc
tags: custom
---

Create a very brief doc in the "flows" directory about the [FLOW NAME] flow, starting from [ENTRY POINT / COMPONENT].

Requirements:
- Keep it very brief, high-level, and abstract.
- Include only a couple of links as entry points for further exploration.
- Do not include implementation details or frequently changing values.
- The doc should stay valid even if small parts of the codebase change.
- Target audience is a newcomer or a code agent who will dig deeper into the codebase on their own if more detail is needed.
